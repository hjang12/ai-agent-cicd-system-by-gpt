# Gatefront

A compact, original 2D browser game inspired by the broad "choose a gate and grow your squad" arcade mechanic.

## Play

Open `index.html` in a static web server or host the project directory as a static site. No build step, backend, account, or external service is required.

## Round

- Start with 12 soldiers.
- Drag left/right on the game field, or use the left/right arrow keys (A/D also works).
- Choose between additive, multiplicative, percentage, and negative gates.
- Your squad fires automatically while you steer.
- Clear three enemy units and defeat the final commander.
- Win or lose, then replay the same single round.

## Scope

One handcrafted round, original Canvas-drawn visuals, responsive HTML/CSS, no external assets or runtime dependencies. Mobile app packaging, persistent progression, monetization, accounts, AI models, and additional levels are out of scope.
